# Guia de Comandos Git

## Comandos básicos vistos em sala

- `git clone <url>` — copia um repositório do GitHub para o computador.
- `git add .` — prepara todas as alterações para o próximo commit.
- `git commit -m "mensagem"` — salva as alterações no histórico com uma mensagem.
- `git push` — envia os commits do computador para o GitHub.

## Outros comandos úteis

- `git init` — transforma a pasta atual em um repositório Git.
- `git status` — mostra quais arquivos foram alterados ou ainda não foram adicionados.
- `git log` — mostra o histórico de commits.
- `git pull` — baixa as atualizações do GitHub para o computador.
- `git remote add origin <url>` — liga o repositório local ao repositório no GitHub.
- `git branch -M main` — renomeia a branch principal para `main`.

## Fluxo do dia a dia

1. Alterar os arquivos
2. `git add .`
3. `git commit -m "descrição do que mudou"`
4. `git push`
